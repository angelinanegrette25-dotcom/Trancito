# Sistema Inteligente para Evitar Comparendos y Multas de Tránsito

Proyecto desarrollado en Python utilizando Programación Orientada a Objetos.

## Descripción

El sistema permite registrar usuarios, vehículos y zonas de control de tránsito para generar alertas preventivas y ayudar a los conductores a evitar comparendos y multas de tránsito.

La aplicación analiza rutas y detecta zonas cercanas con cámaras de velocidad o fotomultas.

## Funcionalidades

- Registro de usuarios
- Registro de vehículos
- Registro de zonas de control
- Gestión de rutas
- Alertas inteligentes
- Historial de trayectos
- Interfaz gráfica
